# Language and Documentation

- All code, comments, Javadoc, documentation, commit messages and file content
  must be written in English, regardless of the language used in the
  conversation.
- When behavior, structure or an API changes, update the documentation that
  describes it in the same change.
- The roadmap in `ARCHITECTURE.md` may lag behind reality; trust `pom.xml` and
  `package.json` versions when the two disagree.
