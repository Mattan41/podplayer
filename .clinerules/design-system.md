# Design System — Zorn Palette

- Follow the Zorn Palette design system: strict four colors.
- Shape language: use `rounded-base`, never intermediate radii such as
  `rounded-sm` or `rounded-md`.
- Theme tokens only: components use `bg-bg` / `text-fg` / `border-fg` /
  `bg-accent` / `bg-cta`. Never hex values or palette names in TSX.
